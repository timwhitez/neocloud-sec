# Changelog

All notable changes to NeoCloud Cyber Security are recorded here.

## 1.0.0-draft.1 — 2026-09-04

### Added

- Bilingual NeoCloud Cyber Security white paper and implementation guide.
- Five-tier adoption model from T0 Guardrails through T4 Adaptive.
- Eighteen-domain security taxonomy covering cloud, GPU/HPC, fabric, AI, agent, supply-chain, and physical security.
- Machine-readable baseline control catalog.
- Reference architecture, 24-month development roadmap, metrics, and continuous-assurance model.
- Assessment, risk, exception, evidence, shared-responsibility, service-catalog, threat-model, and incident-severity templates.

### Status

This release is an implementation-oriented draft. External framework mappings are informative and require independent validation before being used for certification or legal assertions.
