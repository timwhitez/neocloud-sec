# SemiAnalysis / ClusterMAX Public Security Coverage

[English](docs/en/SEMIANALYSIS_COVERAGE.md) | [简体中文](docs/zh-CN/SEMIANALYSIS_COVERAGE.md)

This repository maps the publicly accessible SemiAnalysis NeoCloud security issue patterns and the currently enumerable canonical public ClusterMAX Security-page requirements to the stable NeoCloud Cyber Security control catalog.

本仓库将 SemiAnalysis 公开 NeoCloud 安全问题模式及当前主站公开 ClusterMAX Security 页面可独立枚举的要求，映射到稳定 NeoCloud Cyber Security 控制目录。

## Coverage snapshot / 覆盖快照

- Five public article-level patterns / 5 类公开文章高层问题
- Forty project-authored atomic test patterns / 本项目拆分的 40 项原子测试模式
- Twenty of twenty currently enumerable canonical public Security-page requirements mapped / 当前主站公开 Security 页面 20/20 项已映射
- One unresolved count delta on an alternate host; no 21/21 or exact-parity claim / 备用 Host 存在 1 项数量差异，不声明 21/21 或精确等价
- Three assurance views: tenant black-box, provider white-box, independent failure/recovery / 三类保证视角：租户黑盒、服务商白盒、独立故障/恢复

This is an independent interoperability overlay, not a ClusterMAX score, certification, endorsement, licensed reproduction or proof of provider effectiveness.

这是独立互操作覆盖层，不是 ClusterMAX 分数、认证、背书、授权复刻或服务商有效性证明。

See the [machine-readable profile](controls/semianalysis-public-findings-profile.v1.json), [normative errata](controls/neocloud-security-baseline.v1.errata.json), and [assessment templates](templates/README.md).
